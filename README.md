# NBA Player Replacement – Power BI Dashboard

## Overview

This project was developed for a university course in **Business Intelligence for Management**.  
The aim of the project is to build an interactive **Power BI dashboard** to support the analysis of NBA players and assist in identifying possible player replacements through data-driven insights.

The dashboard combines player performance statistics and salary information in order to provide a clearer view of the relationship between on-court performance and economic value.

## Objective

The main objective of this project is to support player comparison and replacement decisions by using interactive visual analysis.

More specifically, the dashboard aims to:

- compare NBA players across different performance indicators;
- analyse player salary in relation to performance;
- identify potential replacement options;
- support decision-making through clear KPIs and visual insights.

## Dataset

The project uses NBA player statistics and salary data across multiple seasons.

The dataset includes information related to:

- player performance;
- playoff statistics;
- salary data;
- season-by-season comparisons.

The raw data were cleaned and transformed before being used in Power BI.

## Dashboard Structure

The Power BI dashboard includes several analytical sections focused on:

- overall player performance;
- salary and performance relationship;
- player comparison;
- replacement analysis;
- key insights for decision-making.

## Tools Used

- Power BI
- Power Query
- DAX
- CSV datasets
- Data cleaning
- Data visualisation
- KPI analysis

## Skills Demonstrated

This project demonstrates the ability to:

- clean and prepare data for business analysis;
- build an interactive dashboard in Power BI;
- create meaningful KPIs and visualisations;
- analyse the relationship between performance and salary;
- communicate insights through visual storytelling;
- support data-driven decision-making.
